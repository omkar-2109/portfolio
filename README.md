## ⚡ Quick Start

```bash

git clone https://github.com/omkar-2109/portfolio.git

# Navigate to directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
